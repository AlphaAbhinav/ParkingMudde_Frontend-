Wrong Parking Detection System (AI/ML) — Explained for Developer
1) What this system does (Goal)
The Wrong Parking Detection System will automatically judge whether a vehicle is:
✅ Correctly Parked⚠️ Suspicious / Likely Wrong Parking❌ Wrong / Illegal Parking (Reportable + SOS Eligible)
It will use a hybrid model:
✅ Hybrid Approach
AI Vision (Camera Proof) → Detect vehicle location + posture + environment (road marking, zebra crossing, bus stop, footpath etc.)
Geo-fencing + Maps (GPS context) → Detect if vehicle is near restricted zones (intersection, hospital entry, traffic signal, junction etc.)
Rule Engine (Legal Compliance) → Apply Indian Motor Vehicle rules as decision rules
Evidence Validation → Proof required (photos + video + time + location)
Final Decision → Wrong parking score + verdict + action steps
✅ 2) Parking Laws & Rules to implement (from your doc)
These are the core legal clauses that define wrong parking in India:
A) MV Act Section 122 (Danger / Obstruction / Inconvenience)
Wrong if vehicle is:
Creating danger
Creating obstruction
Causing undue inconvenience on public placeLaw of Parking
✅ App interpretation:If vehicle blocks movement, entrance/exit, roadway, pedestrian access → mark as wrong
B) MV Act Section 127 (Towing / Immobilization)
Vehicle can be towed if:
Parked in a place where parking is legally prohibited
Left unattended 10 hours or more
Creating a traffic hazard → immediate removal authorizedLaw of Parking
✅ App interpretation:If detected in legal prohibition zone → mark towable wrong parkingIf long-stationary evidence exists → mark as abandoned / unattended
C) MVDR 2017 Regulation 22 (Stopping + Parking restrictions)
This is the most important for AI detection.
C1) Vehicle shall not STOP in:
Narrow road / obstructed view
Near/on sharp bend
Acceleration/deceleration lane
On or 5m before pedestrian crossing
Level crossing
Within 5m of traffic light / Give Way / Stop sign
Bus stand (if not bus)
Yellow box marking
No Stopping sign zoneLaw of Parking
C2) Vehicle shall not PARK in:
Any “no stopping” zone
Main roads where speed limit ≥ 50 km/h
Footpath / cycle track / pedestrian crossing
50m before or after intersection/junction
Blocking access to parking spaces
Near bus stop / hospital / school entry
In tunnels
Bus lanes
In front of entrance/exit of property
Continuous yellow line on kerb side
Away from the edge of footpath
Opposite another parked vehicle
Obstruct any other vehicle/person
Alongside another parked vehicle (double parking)
Beyond allowed duration
Wrong vehicle category zone
Disabled parking misuse
Occupying excessive space / wrong in parking bay
No Parking sign zoneLaw of Parking
✅ App will use these as rule conditions.

✅ 5) Detailed List of Wrong Parking Detection Algorithms (AI/ML + Rule Engine)
Below is the complete list your mobile app can use.
A) Computer Vision Models (Camera Based)
1. Vehicle Detection + Classification
Algorithm: YOLOv8 / EfficientDet / RetinaNetOutput: Vehicle type, bounding box, confidence
2. Number Plate Detection (VRN ROI)
Algorithm: Plate detector + OCROutput: Plate location + text
Even if OCR fails, reporting can continue using manual VRN.
3. Road Segmentation (Footpath vs Road vs Crossing)
Algorithm: Semantic Segmentation (DeepLabV3+, SegFormer)Detect pixels belonging to:
Road
Footpath
Zebra crossing
Cycle lane
Yellow box area
Bus lane
Parking bay markings (where visible)
✅ This is the backbone of “wrong parking on restricted surface”.
4. Parking Orientation Detection (Angle + Alignment)
Algorithm: Keypoint estimation + bounding box angleDetect if vehicle is:
Parked diagonally across lane
Not aligned in parking bay
Taking excessive space
5. Double Parking Detection
Algorithm: Multi-object detection + lane position comparisonRule:If vehicle is parallel to a parked vehicle and occupying traffic lane → wrong parking.
6. Obstruction Detection (Blocking a Path / Gate / Lane)
Algorithm: Scene graph reasoning + foreground overlapDetect:
Gate / driveway entry blocked
Exit blocked
Fire hydrant block (if sign visible)
Parking slot entry blocked
7. Crosswalk / Pedestrian Zone Violation
Algorithm: Zebra crossing detection + distance estimationRule:Vehicle overlaps crossing → illegalVehicle within 5m (approximation) → illegal
8. Signboard Detection (No Parking / No Stopping)
Algorithm: Object detection model trained on Indian traffic signsDetect:
No Parking sign
No Stopping sign
Stop / Give Way signs
✅ Extremely powerful because it triggers direct legal violation.
9. Sharp Bend / Obstructed View Detection (Optional Advance)
Algorithm: Road curvature estimation from image + map geometryUse caution: hard to be highly accurate without map data.
B) Geo-Fencing + Mapping Algorithms (GPS Based)
10. Intersection / Junction Proximity Check
Algorithm: Map API + radius rulesRule:If within 50m of intersection or junction → illegal parking
11. Traffic Signal Proximity Check
Rule:If within 5m of traffic light / stop sign → illegal stopping/parking
12. Bus Stop / Bus Lane Zone Check
Rule:If within bus stop geofence OR bus lane segment → illegal
13. Hospital / School Entry Zone Check
Rule:If within defined entrance geofence OR “likely blocking entry” → wrong parking
15. Parking Duration Violation Check
Rule:If allowed duration exists and exceeded → illegal(Phase 2: integrate paid parking providers)
C) Rule Engine Logic (Legal Decisioning)
16. Legal Prohibition Rule Match
If any clause triggered → label as wrong parking with reason:
“Footpath parking”
“Blocking entrance”
“Double parking”
“Near crossing”
“Near junction”
“No parking sign zone”
etc.
17. Evidence Confidence Threshold Check
Rule:If AI confidence < threshold → ask user for more proofExample:“Please upload 1 more clear photo from side angle.”
18. Duplicate Report Prevention
Rule:If same VRN + same location + same reason within X minutes→ prevent spam and reduce misuse
19. Registered vs Unregistered Vehicle Handling
Registered → In-app alert + IVR call + SOS ladder
Unregistered → SOS-only route(as per your feature flow)
